Projets

Projet principal

Manaketak

Manaketak est une application web de gestion de commandes de photos scolaires, développée pour répondre aux besoins d'un photographe professionnel. J’ai conçu et développé cette application en autonomie, de l’analyse des besoins jusqu'à sa mise en production. Elle est aujourd'hui utilisée dans le cadre de véritables campagnes de photos scolaires.

Contexte

L’objectif était de simplifier la gestion des commandes de photos scolaires, depuis la consultation des photos par les parents jusqu'au suivi des commandes par les écoles et le photographe. L'application propose des fonctionnalités adaptées aux différents utilisateurs: parents, écoles et administrateur.

Réalisation

  • conception de l’architecture et de la base de données
  • développement d’une API REST sécurisée (Symfony, API Platform)
  • gestion des rôles utilisateurs
  • développement du frontend (Next.js)
  • gestion des commandes
  • génération de PDF, exports Excel et e-mails

Déploiement

  • backend déployé sur Scalingo
  • frontend déployé sur Vercel
  • stockage des fichiers via OVH Object Storage
  • configuration des variables d’environnement

Architecture

L’application repose sur une architecture frontend / backend, avec un stockage externe pour les fichiers.

Démo de l'application

Deux démonstrations courtes montrent les usages côté administrateur et côté parent.

Interface administrateur

Démonstration de la gestion des écoles, des classes et des commandes depuis l’interface administrateur. Vidéo sans son.

Parcours parent

Démonstration du parcours parent : accès aux photos scolaires, consultation des photos, choix des quantités et formats et passage d’une commande. Vidéo sans son.

Test technique

Application de blagues – Carambar

Application web permettant d'afficher des blagues Carambar aléatoires, développée avec une API REST et une interface utilisateur simple.

Contexte

Ce projet a été réalisé dans le cadre d’un test technique de sélection, à partir d'un cahier des charges imposé. Il comprenait le développement d’une API REST versionnée, d’une interface frontend et leur déploiement.

Réalisation

  • développement d’une API REST (Node.js, Express, Sequelize, SQLite)
  • création des endpoints : liste, détail, ajout et blague aléatoire
  • développement d’une interface permettant d'afficher une blague aléatoire
  • documentation de l’API avec Swagger
  • déploiement du backend sur Render et du frontend sur GitHub Pages

Interface

Version desktop et mobile

Ce que ce projet m'a permis de travailler

  • analyse et respect d'un cahier des charges
  • développement et connexion d'une API REST à une interface frontend
  • organisation et réalisation d'un projet dans un délai contraint

Tester l’API

L'API peut être testée depuis sa documentation Swagger, qui permet de consulter les différents endpoints et d'ajouter de nouvelles blagues.

L'application étant hébergée sur un service gratuit, la base de données peut être réinitialisée.

Projet personnel

Mus Score App

Application web progressive (PWA) permettant de compter les points lors d'une partie de Mus, un jeu de cartes traditionnel basque, conçue pour une utilisation simple et rapide sur smartphone.

Contexte

Ce projet est né d'un besoin personnel : pouvoir compter facilement les points pendant une partie de Mus, sans avoir besoin de matériel de comptage et en gardant le score accessible sur son téléphone.

Fonctionnalités

  • comptage des ttantto et hamarreko
  • conversion automatique des points
  • détection de la victoire et animation visuelle
  • personnalisation des noms des équipes
  • sauvegarde automatique de la partie
  • interface bilingue (basque / français)

Interface

Icône de l'application et capture de l'interface mobile

Ce que ce projet m’a permis de travailler

  • développement d’une Progressive Web App (PWA)
  • conception d'une interface mobile-first et responsive
  • sauvegarde des données avec localStorage
  • déploiement automatisé sur GitHub Pages
