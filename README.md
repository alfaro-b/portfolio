## Projet principal

### Manaketak

Application web de gestion des commandes de photos scolaires, développée pour un photographe professionnel et utilisée en production.

- API REST sécurisée avec Symfony et API Platform   
- Frontend développé avec Next.js   
- Gestion des utilisateurs et des commandes   
- Déploiement sur Scalingo et Vercel   
- Stockage des fichiers sur OVH Object Storage

## Autres projets

### Application de blagues – Carambar

Application web réalisée dans le cadre d'un test technique, à partir d'un cahier des charges imposé.   

- API REST avec Node.js, Express, Sequelize et SQLite   
- Interface frontend permettant d'afficher des blagues aléatoires   
- Documentation de l'API avec Swagger   
- Déploiement sur Render et GitHub Pages   

### Mus Score App

Application web progressive (PWA) permettant de compter les points lors d'une partie de Mus, jeu de cartes traditionnel basque.   

- Interface mobile-first et responsive   
- Sauvegarde locale des données avec localStorage   
- Inteface bilingue basque / français   
- Fonctionnement hors ligne et installation sur mobile PWA   
- Déploiement via GitHub Pages
